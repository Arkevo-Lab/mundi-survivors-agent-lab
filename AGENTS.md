# Independent Survivors Agent Lab

This is the company's independent three-layer agent research repository, not MUNDI Web.

- Do not modify or depend on the MUNDI Web checkout, account database, production configuration or deployment services.
- Preserve the R165 strategy/navigation/micro contracts and record intentional behavioral changes separately.
- Use only explicit user-owned local model credentials. Never commit keys, `.env`, local state, raw provider outputs or private game media.
- `npm run check` performs offline tests and build. Real provider calls or autonomous experiments require explicit user authorization.
- The default server is loopback only. Do not publish a public service or enable an automation as part of code review or packaging.
- Record source snapshot hashes and actual verification. Historical full-host tests are not this repository's test results.
